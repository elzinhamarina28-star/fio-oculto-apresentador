# Fio Oculto Apresentador

Implemente agora a primeira versão funcional do apresentador da Fio Oculto.



Utilize os arquivos de imagem enviados:



- Cenário como fundo fixo.

- Personagem como camada independente, posicionado sentado na cadeira gamer.



Desenvolva:



- Animação de respiração e piscadas.

- Pequenos movimentos de cabeça.

- Expressões de felicidade e surpresa.

- Reação visual a curtidas, seguidores e presentes.

- Painel de controle para testar cada animação manualmente.



Preserve a identidade visual e as funcionalidades existentes.



Importante: não simule movimentos complexos com partes inexistentes na imagem. Prepare a estrutura para futura animação com personagem rigado ou Live2D.



Não implemente dados fictícios como eventos reais do TikTok.
